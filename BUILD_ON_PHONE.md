# Ringo V3 — Build APK from an Android phone

1. Create/sign in to a GitHub account in Chrome.
2. Create a new repository (for example: `Ringo-Android-V3`).
3. Upload the contents of this project ZIP to the repository.
4. Open **Actions** → **Build Ringo APK** → **Run workflow**.
5. Wait for the green check.
6. Open the workflow run → **Artifacts** → **Ringo-debug-apk**.
7. Download the ZIP, extract `app-debug.apk`, and install it on the phone.

No PC/laptop is required.
